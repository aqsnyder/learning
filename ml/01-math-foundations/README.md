# Mathematical Foundations

## Why This Section Matters

Mathematics is the language of machine learning. Linear algebra tells you how data and transformations are represented; calculus tells you how models learn via gradients; probability and statistics tell you how to reason under uncertainty. You don't need to be a mathematician, but building solid intuition in these areas will make every subsequent section dramatically easier to understand — and will let you read papers rather than just blog summaries.

---

## Prerequisites

- Basic high school algebra

## Suggested Order

1. **3Blue1Brown — Essence of Linear Algebra** — Start here to build visual intuition for vectors, matrices, and transformations.
2. **3Blue1Brown — Essence of Calculus** — Understand derivatives and the chain rule, which power backpropagation.
3. **3Blue1Brown — Neural Networks** — See the math come together in the context of neural networks.
4. **Mathematics for Machine Learning (book)** — Work through this for a more rigorous treatment, using it as a reference alongside the videos.
5. **Khan Academy / StatQuest** — Fill in any gaps in probability, statistics, or specific topics as needed.
6. **Ilya list items** (Aaronson, Grünwald, Kolmogorov) — Tackle these for deeper theoretical perspective once you have the basics down.
