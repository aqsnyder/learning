# 📈 Economics, Decision Theory & Game Theory — A Learning Journey

> The mathematics of incentives, strategy, and coordination.

## Purpose

This repository is a structured curriculum for self-studying economics, decision theory, and game theory. It compiles the most important books, papers, video lectures, blog posts, and online courses into a coherent learning path — from basic economic thinking through frontier topics in cooperative AI and mechanism design.

**Designed for pairing with [NotebookLM](https://notebooklm.google.com/)** — feed individual sections or papers into NotebookLM for interactive study sessions.

## Learning Path

**Start here: [Section 00 — Economic Thinking](00-economic-thinking/).** Take the sections top to bottom: the table is in recommended order, and *When* flags the sections whose number doesn't match their place. In each section, read the 🎯 objectives, follow the core path (the 🔑 must-reads, at most three), do at least two 🛠️ exercises and answer ✅ Check Yourself from memory, then tick the section off in [PROGRESS.md](PROGRESS.md). For routes that combine curricula, see the tracks in the [Study Guide](../STUDY-GUIDE.md).

## How to Use with NotebookLM

1. **Section-by-section**: Upload a section's README to NotebookLM as a source for study guidance
2. **Papers**: Download PDFs of papers and upload them directly for deep-dive conversations
3. **Books**: Upload free book chapters or PDFs for interactive Q&A
4. **Progress tracking**: run `python tools/progress.py init` once from the repo root, then tick items in your private copy, `my/progress/econ.md`. [PROGRESS.md](PROGRESS.md) is the blank template it copies from
