## Suggested Order

1. **Programming Bitcoin** — Build a Bitcoin library from scratch to internalize the protocol.
2. **Bitcoin Core source code** — Clone the repo and explore the codebase structure.
3. **Bitcoin Developer Documentation** — Familiarize yourself with the official reference.
4. **Bitcoin Core RPC API** — Start interacting with a node programmatically.
5. **Set up Bitcoin Core on testnet/signet** — Get hands-on with a running node.
6. **Chaincode Labs Bitcoin Curriculum** — Work through the professional training material.
7. **BTrust Builders pathway** — Follow the structured 8-week program.
8. **Saylor University CS120** — Supplement with a formal developer course.
9. **Bitcoin Core PR Review Club** — Learn by reviewing real pull requests.
10. **bitcoin-dev mailing list** — Follow protocol discussions and engage with the community.
