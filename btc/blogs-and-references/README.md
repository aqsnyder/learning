# Essential Resources, Tools, and Community

## Must-Bookmark Sites

- 🔑 [Lopp.net Bitcoin Resources](https://www.lopp.net/bitcoin-information.html) — THE most comprehensive Bitcoin resource hub
- 🔑 [Learn Me A Bitcoin](https://learnmeabitcoin.com/) — Interactive technical explanations
- 🔑 [Bitcoin Developer Documentation](https://developer.bitcoin.org/) — Official protocol docs
- 🔑 [Satoshi Nakamoto Institute](https://satoshi.nakamotoinstitute.org/) — Primary source material
- [Bitcoin Wiki](https://en.bitcoin.it/) — Community-maintained reference
- [Bitcoin Optech](https://bitcoinops.org/) — Weekly technical newsletter
- [Bitcoin.page](https://bitcoin.page/) — Curated link collection

## Blockchain Explorers

- 🔑 [Mempool.space](https://mempool.space/) — Best open-source explorer
- [Blockstream Explorer](https://blockstream.info/)
- [OXT.me](https://oxt.me/) — Privacy-focused analysis

## Development Tools

- 🔑 [Bitcoin Core](https://github.com/bitcoin/bitcoin) — Reference implementation
- [BIP Repository](https://github.com/bitcoin/bips) — All Bitcoin Improvement Proposals
- Bitcoin Testnet/Signet — Practice without real bitcoin
- [Polar](https://lightningpolar.com/) — Local Lightning Network testing
