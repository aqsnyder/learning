# Essential Resources, Tools, and Community

## Must-Bookmark Sites

- 🔑 [Lopp.net Bitcoin Resources](https://www.lopp.net/bitcoin-information.html) — THE most comprehensive Bitcoin resource hub
- 🔑 [Learn Me A Bitcoin](https://learnmeabitcoin.com/) — Interactive technical explanations
- 🔑 [Bitcoin Developer Documentation](https://developer.bitcoin.org/) — bitcoin.org's community-written protocol docs; good background but unmaintained since about 2021 (not official Bitcoin Core documentation)
- 🔑 [Satoshi Nakamoto Institute](https://satoshi.nakamotoinstitute.org/) — Primary source material
- [Bitcoin Wiki](https://en.bitcoin.it/) — Community-maintained reference
- 🔑 [Bitcoin Optech](https://bitcoinops.org/) — Weekly technical newsletter, plus the [Topics index](https://bitcoinops.org/en/topics/): per-topic histories and current status of every proposal
- [Bitcoin.page](https://bitcoin.page/) — Curated link collection

## Blockchain Explorers

- 🔑 [Mempool.space](https://mempool.space/) — Best open-source explorer
- [Blockstream Explorer](https://blockstream.info/)
- [OXT.me](https://oxt.me/) — Privacy-focused analysis

## Development Tools

- 🔑 [Bitcoin Core](https://github.com/bitcoin/bitcoin) — Reference implementation
- [Bitcoin Core documentation](https://bitcoincore.org/en/doc/) — Official, versioned RPC reference (use this rather than developer.bitcoin.org's frozen copy)
- [BIP Repository](https://github.com/bitcoin/bips) — All Bitcoin Improvement Proposals (statuses follow BIP 3: Draft / Complete / Deployed / Closed)
- Bitcoin Regtest / Signet / Testnet4 — Practice without real bitcoin (testnet3 is being phased out)
- [Polar](https://lightningpolar.com/) — Local Lightning Network testing

## Node Software

- [Bitcoin Core](https://bitcoincore.org/)
- [LND](https://github.com/lightningnetwork/lnd)
- [Core Lightning (CLN)](https://github.com/ElementsProject/lightning)
- [LDK (Lightning Dev Kit)](https://lightningdevkit.org/)
- [Eclair](https://github.com/ACINQ/eclair) — ACINQ's Scala Lightning implementation (the fourth implementation named in Section 07)
- [Bitcoin Knots](https://github.com/bitcoinknots/bitcoin) — Alternative full-node implementation derived from Bitcoin Core (compare its policy defaults with Core's when reading Section 06's relay-policy material)

## Community

- [Bitcoin Development Mailing List](https://groups.google.com/g/bitcoindev) — Protocol proposals (moved off the Linux Foundation list; archive at [gnusha.org](https://gnusha.org/pi/bitcoindev/))
- [Delving Bitcoin](https://delvingbitcoin.org/) — Developer forum for protocol and Lightning design discussion
- [Bitcoin Stack Exchange](https://bitcoin.stackexchange.com/)
- [Bitcoin Talk Forum](https://bitcointalk.org/)
- Bitcoin++ Conference — Developer-focused conference
- TABConf — Technical conference
- Advancing Bitcoin — London-based technical conference
