# Recommended Books

These books are ordered from accessible to technical. Do not read cover-to-cover; use as companions to the section READMEs. Start with the whitepaper, then Mastering Bitcoin, then branch out.

| # | Priority | Title | Author(s) | Year | Free? | Level | Link | Notes |
|---|----------|-------|-----------|------|-------|-------|------|-------|
| 1 | 🔑 | Mastering Bitcoin: Programming the Open Blockchain | Andreas Antonopoulos and David Harding | 3rd ed | Free on GitHub | Beginner/Intermediate | [GitHub](https://github.com/bitcoinbook/bitcoinbook) | THE technical Bitcoin reference |
| 2 | 🔑 | The Bitcoin Standard | Saifedean Ammous | 2018 | Paid | Beginner | | History of money and Bitcoin's economic thesis |
| 3 | 🔑 | Programming Bitcoin | Jimmy Song | 2019 | Paid | Intermediate | | Build Bitcoin from scratch in Python |
| 4 | 🔑 | Grokking Bitcoin | Kalle Rosenbaum | 2019 | Paid | Beginner | | Best visual explanations of the protocol |
| 5 | 🔑 | Mastering the Lightning Network | Antonopoulos, Osuntokun, Pickhardt | | Free on GitHub | Intermediate | [GitHub](https://github.com/lnbook/lnbook) | THE Lightning reference |
| 6 | | Digital Gold | Nathaniel Popper | 2015 | Paid | Beginner | | Historical narrative of Bitcoin's early days |
| 7 | | The Internet of Money (Vols 1-3) | Andreas Antonopoulos | | Paid | Beginner | | Accessible talks on why Bitcoin matters |
| 8 | | The Fiat Standard | Saifedean Ammous | 2021 | Paid | Beginner | | Companion analyzing the fiat system |
