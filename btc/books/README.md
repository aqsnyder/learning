# Recommended Books

These books are ordered from accessible to technical. Do not read cover-to-cover; use as companions to the section READMEs. Start with the whitepaper, then Mastering Bitcoin, then branch out.

| # | Priority | Title | Author(s) | Year | Free? | Level | Link | Notes |
|---|----------|-------|-----------|------|-------|-------|------|-------|
| 1 | 🔑 | Mastering Bitcoin: Programming the Open Blockchain | Andreas Antonopoulos and David Harding | 2023 (3rd ed.) | Free on GitHub (CC BY-SA 4.0) | Beginner/Intermediate | [GitHub](https://github.com/bitcoinbook/bitcoinbook) | THE technical Bitcoin reference; the 3rd edition covers Taproot, descriptors, and modern fee policy |
| 2 | 🔑 | The Bitcoin Standard | Saifedean Ammous | 2018 | Paid | Beginner | | History of money and Bitcoin's economic thesis — Austrian-school advocacy; read critically |
| 3 | 🔑 | Programming Bitcoin | Jimmy Song | 2019 | Free on GitHub (CC BY-NC-ND) | Intermediate | [GitHub](https://github.com/jimmysong/programmingbitcoin) | Build Bitcoin from scratch in Python (pre-Taproot) |
| 4 | 🔑 | Grokking Bitcoin | Kalle Rosenbaum | 2019 | Free online (CC BY-NC-SA) | Beginner | [rosenbaum.se](https://rosenbaum.se/book/) | Best visual explanations of the protocol |
| 5 | 🔑 | Mastering the Lightning Network | Antonopoulos, Osuntokun, Pickhardt | 2021 | Free on GitHub | Intermediate | [GitHub](https://github.com/lnbook/lnbook) | THE Lightning reference (predates BOLT 12 offers and splicing) |
| 6 | | Digital Gold | Nathaniel Popper | 2015 | Paid | Beginner | | Historical narrative of Bitcoin's early days |

| 9 | | The Little Bitcoin Book | Jimmy Song et al | | Paid | Beginner | | Short, accessible intro |

| 12 | | Inventing Bitcoin | Yan Pritzker | 2019 | Paid | Beginner | | Concise technical intro for non-programmers |
