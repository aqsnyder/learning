# ₿ Bitcoin — A Learning Journey

> A curated, ordered collection of the best resources for deeply understanding Bitcoin — from cypherpunk history to protocol development.

## Purpose

This repository is a structured curriculum for self-studying Bitcoin at a technical level. It compiles the most important books, papers, courses, standards (BIPs), tools, and community resources into a coherent learning path.

**Designed for pairing with [NotebookLM](https://notebooklm.google.com/)** — feed individual sections, the whitepaper, or book chapters into NotebookLM for interactive study sessions.
