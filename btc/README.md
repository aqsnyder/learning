# ₿ Bitcoin — A Learning Journey

> A curated, ordered collection of the best resources for deeply understanding Bitcoin — from cypherpunk history to protocol development.

## Purpose

This repository is a structured curriculum for self-studying Bitcoin at a technical level. It compiles the most important books, papers, courses, standards (BIPs), tools, and community resources into a coherent learning path.

**Designed for pairing with [NotebookLM](https://notebooklm.google.com/)** — feed individual sections, the whitepaper, or book chapters into NotebookLM for interactive study sessions.

## Learning Path

**Start here: [Section 00 — History and Philosophy](00-history-and-philosophy/).** Take the sections top to bottom: the table is in recommended order, and *When* flags the sections whose number doesn't match their place. In each section, read the 🎯 objectives, follow the core path (the 🔑 must-reads, at most three), do at least two 🛠️ exercises and answer ✅ Check Yourself from memory, then tick the section off in [PROGRESS.md](PROGRESS.md). For routes that combine curricula, see the tracks in the [Study Guide](../STUDY-GUIDE.md).

## How to Use with NotebookLM

1. **Section-by-section**: Upload a section's README for study guidance
2. **Whitepaper**: Upload the Bitcoin whitepaper for deep-dive Q&A
3. **Books**: Upload Mastering Bitcoin chapters for interactive study
4. **BIPs**: Upload specific BIP documents for protocol deep dives
5. **Progress tracking**: run `python tools/progress.py init` once from the repo root, then tick items in your private copy, `my/progress/btc.md`. [PROGRESS.md](PROGRESS.md) is the blank template it copies from

## Keeping Current
