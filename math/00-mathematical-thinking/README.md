# Mathematical Thinking

## Why This Section Matters

Before you can learn any advanced mathematics, you need to learn how mathematicians *think*. This section builds the foundational skills of logical reasoning, proof writing, and problem-solving strategy that underpin every other section in this curriculum. Without these skills, you'll be memorizing formulas instead of understanding structures — and you'll hit a wall the moment you encounter unfamiliar territory. Mathematical maturity isn't about knowing more theorems; it's about being comfortable with abstraction, rigor, and the creative process of discovery.

## Suggested Order

1. **Devlin's Coursera course** — Start here if transitioning from computational/applied math. Builds the right mindset.
2. **Book of Proof (Hammack)** — Read alongside or before Velleman. Free and accessible.
3. **How to Prove It (Velleman)** — The core text. Work through the exercises — proofs are learned by doing, not reading.
4. **How to Solve It (Pólya)** — Read for problem-solving strategy. Applicable to every section that follows.
5. **Halmos — Naïve Set Theory** — Optional but valuable. Deepens set-theoretic foundations.
6. **Epp — Discrete Mathematics** — Use as a reference and problem source throughout.
