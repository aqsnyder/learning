# Essential Blogs, References, and Community Resources

---

## Must-Follow Blogs

| Priority | Blog | Description |
|----------|------|-------------|
| 🔑 | [Terence Tao's Blog](https://terrytao.wordpress.com/) | The blog of a Fields Medalist. Covers everything from analysis to combinatorics to number theory. Tao's exposition is remarkably clear, and his career advice posts are invaluable. |
| 🔑 | [Math3ma](https://www.math3ma.com/) | Tai-Danae Bradley's blog making abstract mathematics (topology, category theory, algebra) beautiful and accessible. Visual, intuitive, and deep. |
| 🔑 | [3Blue1Brown](https://www.3blue1brown.com/) | Grant Sanderson's legendary visual math channel. The gold standard for mathematical visualization and intuition-building. |
| | [n-Category Café](https://golem.ph.utexas.edu/category/) | Group blog on category theory, higher algebra, topology, and mathematical physics. Advanced but thought-provoking. John Baez's posts are particularly accessible. |
| | [Quanta Magazine — Mathematics](https://www.quantamagazine.org/mathematics/) | Award-winning science journalism covering breakthrough results in mathematics. Accessible to non-specialists and genuinely exciting. |
| | [Colah's Blog](https://colah.github.io/) | While primarily ML-focused, Olah's visual approach to mathematical concepts (information theory, manifolds, topology) is exceptional. |
| | [Better Explained](https://betterexplained.com/) | Intuition-first explanations of mathematical concepts. Particularly strong on calculus, linear algebra, and Fourier transforms. |
| | [The n-Lab](https://ncatlab.org/) | The wiki of higher category theory and related mathematics. Dense but comprehensive reference for advanced topics. |

## Reference Tools

| Resource | Description |
|----------|-------------|
| [Wolfram MathWorld](https://mathworld.wolfram.com/) | Comprehensive mathematical reference with definitions, theorems, and visualizations |
| [OEIS — Online Encyclopedia of Integer Sequences](https://oeis.org/) | Look up any integer sequence. Invaluable for combinatorics and number theory |
| [The Matrix Cookbook](https://www.math.uwaterloo.ca/~hwolkowi/matrixcookbook.pdf) | Essential reference for matrix identities, derivatives, and decompositions |
| [ProofWiki](https://proofwiki.org/) | Online compendium of mathematical proofs. Good for checking your work |
| [Desmos](https://www.desmos.com/) | Free online graphing calculator. Excellent for visualizing functions and exploring concepts |
