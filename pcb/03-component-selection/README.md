## Suggested Order

1. **DigiKey / Mouser parametric search** — Learn to filter by specs, stock, and lifecycle status; this is a daily skill.
2. **Phil's Lab component selection guides** — Watch practical walkthroughs of choosing regulators, MCUs, passives, etc.
3. **Octopart** — Use for cross-distributor price and availability comparisons.
4. **JLCPCB Parts Library** — Check part availability early if targeting JLCPCB assembly.
5. **JEDEC standards overview** — Familiarize yourself with package naming so you can read datasheets fluently.
6. **Design for Supply Chain** — Internalize the practice of choosing multi-sourced, in-production parts from the start.
