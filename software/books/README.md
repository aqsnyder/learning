# Recommended Books

> These books are ordered from foundational to advanced. Focus on reading for comprehension and architectural insight, not on coding exercises. Many of these teach you to **READ** code better, not write more of it.
>
> **Primary languages:** Python + Embedded C | **Context:** The age of AI-assisted development
