# 🏗️ Software Engineering — A Learning Journey

> A curated curriculum for mastering software engineering in the age of AI — focused on **reading, understanding, and architecting** code, not typing it line by line.

## Philosophy

The future of software development is **agentic**: AI agents write most of the code while humans provide architectural direction, review output, and ensure correctness. This curriculum prepares you to be the **senior architect** — the decision-maker who understands systems deeply enough to guide AI tools effectively.

**Focus areas:**
- 🐍 **Python** — the lingua franca of AI, automation, and rapid prototyping
- ⚡ **Embedded C** — where software meets hardware and real-time constraints
- 🏗️ **Architecture** — the skill AI cannot replace
- 🤖 **AI-assisted workflows** — orchestrating agents, not competing with them

**Designed for pairing with [NotebookLM](https://notebooklm.google.com/)** — feed sections, book chapters, or architecture docs into NotebookLM for interactive study.

## The Architect's Mindset

> *"The best architects don't write the most code — they read the most code, ask the hardest questions, and make the decisions that prevent disasters."*

This curriculum emphasizes:

| Traditional Skill | Architect's Skill |
|-------------------|-------------------|
| Writing code from scratch | **Reading and understanding** unfamiliar codebases |
| Typing implementations | **Reviewing** AI-generated code critically |
| Memorizing syntax | **Recognizing** patterns and anti-patterns |
| Solving algorithm puzzles | **Evaluating** architectural trade-offs |
| Building features | **Designing** systems that scale |
| Writing tests | **Evaluating** whether tests actually test the right things |
